# Frontend Pages Overview — Cyber Security Test Pipeline

## Project Context
- **Frontend**: React + TypeScript + Vite, located in `frontend/`
- **Backend**: Python FastAPI service, located in `src/dashboard/fastapi/`
- **Routing**: `frontend/src/RouteConfig.tsx` defines all routes with lazy loading, error boundaries, and route guards
- **Route Meta**: `frontend/src/config/routes.ts` contains page titles/subtitles and prefetch map

---

## Authentication & Public Pages

### `/login` — LoginPage
**What it does:**
- Entry point for unauthenticated users
- Supports three auth methods:
  - **Name/Role login** — analyst or viewer role selection
  - **API key authentication** — for programmatic/service access
  - **Guest token login** — if `enableGuestLogin` is enabled in settings
- Redirects authenticated users to their intended destination (`location.state.from`)
- Shows shake animation on auth failure

**Backend support:** Yes — `src/dashboard/fastapi/routers/` includes security/auth routers. The `useAuth` hook calls backend login endpoints.

## Core Operations Pages

### `/` — DashboardPage
**What it does:**
- Primary security operations overview
- Displays dashboard stats (findings count, job stats, health indicators)
- Auto-refreshes every 10 seconds via `useApi` polling
- Shows findings overview, recent jobs, and stale data indicators
- Persists stats to `sessionStorage` for offline resilience
- Renders `FindingsOverview` component and job summary cards

**Backend support:** Yes — `GET /api/dashboard` returns `DashboardStats`. Jobs context feeds from WebSocket/SSE.

---

### `/targets` — TargetsPage
**What it does:**
- Full target/asset management interface
- Lists all scan targets with KPIs (critical findings, avg findings, total count)
- Supports filtering by severity, search query, and status

- Bulk actions: select multiple targets, scan progress tracking
- Import targets via Semgrep or scope file upload (`UrlCollectionSystem`, `ScopeImportModal`)
- Scan progress panel with real-time updates
- Filter panel with severity chips and active filter indicators

**Backend support:** Yes — `src/dashboard/fastapi/routers/targets.py`, `targets/crud.py`, `targets/scoring.py`. Frontend calls `/api/targets`.

## Architecture Notes

1. **Lazy Loading**: All pages use `lazyWithPrefetch` for code-splitting. Prefetch map in `routes.ts` defines hover-prefetch behavior.
2. **Route Guards**: `RouteGuard` component enforces authentication (`user` check) and role-based access (`requiredRole`, `requiredPermission`).
3. **Error Boundaries**: `SuspenseErrorBoundary` catches chunk load errors; `RouteErrorBoundary` catches runtime route crashes. Both track errors via `errorTracker`.
4. **SSE/WebSocket**: Jobs, cockpit, mesh health, and pipeline pages use Server-Sent Events for real-time updates.
5. **Offline Resilience**: Dashboard and findings pages use `sessionStorage` persistence and `offlineQueue` for action replay.
6. **Motion Policy**: `useMotionPolicy` and `useMotionPolicyContext` allow users to reduce/disable animations for accessibility/performance.
7. **i18n**: Frontend has `i18n/en` and `i18n/es` locales, though most UI text appears hardcoded in English.
8. **PWA**: `pwa.ts` utility suggests Service Worker registration for offline support.
